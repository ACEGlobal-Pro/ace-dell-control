# Privacy

ACE Dell Control collects nothing and transmits nothing. It has no accounts,
analytics, telemetry or update check, and makes no network connections.

It reads the computer model and sensor data (temperatures, fan speed) from the
local machine. It writes an activity log that mirrors the on-screen log to
`%ProgramData%\ACE Dell Control\logs\` on your own computer. Logs stay local;
nothing uploads them. If you report a problem, you choose whether to share a log,
and it can contain the computer model and the commands the app ran. Delete the
folder at any time; uninstalling may leave it behind.
